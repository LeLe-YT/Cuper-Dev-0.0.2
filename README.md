## 🎮 Über das Spiel
In **Cuper Dev** dreht sich alles um Präzision und Timing. 
Du steuerst einen Würfel durch herausfordernde Level. Das Besondere? Die Steuerung erfolgt komplett per **Mausklick**! Ein Klick zur richtigen Zeit entscheidet über Sieg oder Niederlage.

### Key Features
* **One-Button-Control:** Einfach zu lernen, schwer zu meistern.
* **Minimalistisches Design:** Fokus auf Gameplay und Flow.
* **Physik-Elemente:** Dynamische Bewegungen in einer 2D-Welt.
